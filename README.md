# Fortnite Web — Box PvP + Battle Royale

A single-file Three.js game. Open `fortnite_battle_royale.html` in any modern browser — no build step, no server needed.

## Modes
- **Box PvP** — the original creative build arena vs one bot.
- **Battle Royale** — Battle Bus drop, 480x480 island with 7 POIs, gliding, storm with 6 shrinking phases, 12/24/36 bots, chests + floor loot, 5 rarities, 6 weapons, consumables, harvestable trees/rocks/crates for materials, kill feed, minimap, Victory Royale.

## Controls (defaults, rebindable in Settings)
WASD move · Space jump · Shift sprint · 1 pickaxe · 2-6 weapon/build slots · E interact/pickup · Q reload · F edit · Left click attack / place · Wheel / slot keys switch · B toggle build mode · Tab map info · Esc menu
